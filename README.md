## Install

<details open><summary><img alt="Windows" height="22" src="https://img.shields.io/badge/os-windows-089ae8?style=flat-square&labelColor=071727&logo=data%3Aimage%2Fsvg%2Bxml%3Bbase64%2CPHN2ZyB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciIHZpZXdCb3g9IjAgMCA4OCA4OCI%2BPHBhdGggZmlsbD0iI2ZmZmZmZiIgZD0iTTAgMTIuNCAzNS43IDcuNXYzNC4zSDB6TTQwIDYuOSA4OCAwdjQxLjhINDB6TTAgNDYuMmgzNS43djM0LjRMMCA3NS42ek00MCA0Ni4yaDQ4Vjg4bC00OC02Ljl6Ii8%2BPC9zdmc%2B&logoColor=ffffff"></summary>

1. Download `electrum-stratis-v2.7.19.exe` from the release page.
2. Run the installer and keep the default location.
3. Launch Electrum-Stratis and choose Create or Recover.
4. Write the seed on paper before sending any coins.

</details>

<details><summary><img alt="macOS" height="22" src="https://img.shields.io/badge/os-macos-089ae8?style=flat-square&labelColor=071727&logo=apple&logoColor=ffffff"></summary>

1. Download `electrum-stratis-v2.7.19.dmg`.
2. Open the image and drag the app to Applications.
3. Launch it from Applications, not from the mounted image.

</details>

<details><summary><img alt="Linux" height="22" src="https://img.shields.io/badge/os-linux-089ae8?style=flat-square&labelColor=071727&logo=linux&logoColor=ffffff"></summary>

1. Download `electrum-stratis-v2.7.19.zip`.
2. Extract it to a folder you own.
3. Run the executable inside the extracted folder; no system Python or Qt install is needed.

</details>

## Features

- Self-custody keys with a seed you can write down and restore.
- Server list with probing, so a failed server is a retry rather than a dead end.
- Standard, multisig and imported wallets, each named before it is created.
- Key export and sweep for coins held in the legacy Qt wallet.
- Cold staking support, with the lock countdown shown before you commit.
- Address verification string in the receive view.
